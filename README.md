# TUXCLOCK

**TUXCLOCK** is a lightweight, stylish desktop clock overlay for Windows 11 featuring transparent backgrounds, configurable fonts, custom digital sizing, and a system tray controls menu.

---

## How to Run TUXCLOCK (Windows 11)

### Option 1: Direct Execution (Portable EXE)
1. Download the latest `tuxclock.exe` file from the **dist** folder or release page.
2. Double-click `tuxclock.exe` to launch the clock immediately.
3. The clock will display directly on your screen without any installation required.

---

## Application Controls & Usage

### Moving the Clock
* **Drag and Drop:** Click and hold the left mouse button over the clock digits to move it anywhere on your desktop.

### System Tray Menu Controls
Locate the **TIME icon** in your Windows System Tray (bottom-right area near the system taskbar). **Right-click** the icon to access all options:

* **Size:** Choose digit height (**50px**, **100px**, **200px**, **300px**, **500px**).
* **Color:** Switch text color between **Black** and **White**.
* **Font:** Toggle between **Courier New** and **Arial Black**.
* **Run with Windows:** Enable or disable automatic startup when Windows starts.
* **Always on the top:** Keep the clock visible over all open windows.
* **Lock position:** Lock the clock position to prevent accidental dragging.
* **About:** Open the DOS-style information dialog.
* **Exit:** Fully close the application.

# TUXCLOCK

**TUXCLOCK** je lehký a stylový překryvný stolní hodinový widget pro Windows 11, který nabízí průhledné pozadí, nastavitelná písma, přizpůsobitelnou velikost číslic a ovládací menu v systémové liště.

---

## Jak spustit TUXCLOCK (Windows 11)

### Možnost 1: Přímé spuštění (přenosný soubor EXE)
1. Stáhněte si nejnovější soubor `tuxclock.exe` ze složky **dist** nebo ze stránky s vydanými verzemi.
2. Dvojitým kliknutím na soubor `tuxclock.exe` hodiny okamžitě spustíte.
3. Hodiny se zobrazí přímo na obrazovce, aniž by byla nutná jakákoli instalace.

---

## Ovládání a používání aplikace

### Přesouvání hodin
* **Přetažení myší:** Klikněte a podržte levé tlačítko myši na číslicích hodin a přesuňte je kamkoli na plochu.

### Ovládací prvky v nabídce systémové lišty
Najděte **ikonu TIME** v systémové liště Windows (v pravém dolním rohu poblíž systémové lišty). **Kliknutím pravým tlačítkem myši** na ikonu zobrazíte všechny možnosti:

* **Velikost:** Vyberte výšku číslic (**50px**, **100px**, **200px**, **300px**, **500px**).
* **Barva:** Přepínejte mezi barvami textu **černá** a **bílá**.
* **Písmo:** Přepínejte mezi písmy **Courier New** a **Arial Black**.
* **Spouštět s Windows:** Zapněte nebo vypněte automatické spuštění při startu systému Windows.
* **Vždy nahoře:** Udržujte hodiny viditelné nad všemi otevřenými okny.
* **Zamknout polohu:** Zamkněte polohu hodin, abyste zabránili náhodnému přetažení.
* **O aplikaci:** Otevře informační dialogové okno ve stylu DOSu.
* **Ukončit:** Úplně zavře aplikaci.
